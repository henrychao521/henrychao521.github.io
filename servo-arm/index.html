手機 / 平板上的操作

兩個互動頁在窄螢幕會自動改成上下堆疊（3D 視圖在上、編輯器在下）。 3D 視圖單指拖曳可旋轉、雙指縮放。程式碼編輯在手機上可用但不好打字， 建議手機看模擬、電腦寫程式。

啟動與停止

# 啟動（前景）
cd ~/3d/servo-arm/sim && ../.venv/bin/python serve_playground.py

# 只綁本機，不對 Tailscale 開放
../.venv/bin/python serve_playground.py --no-tailscale

# 遠端再加一層密碼
../.venv/bin/python serve_playground.py --auth
這是靜態發布版 可用：Arduino 程式碼編譯、時間軸、3D 運動學預覽、匯出 .ino、以及完整的專案記錄。
需要本機伺服器：「送去 MuJoCo 跑物理」——真實物理是在本機跑 MuJoCo， 沒有辦法放在靜態主機上。下方影片是本機實跑錄下來的結果，不是動畫。
